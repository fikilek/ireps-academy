Guest is excluded from the current role catalogue. An unsigned-in person is an access state, not an additional Academy role. Do not infer that a manager or administrator can execute every fieldworker action.

The organisation layer (utility/municipality, main contractor, subcontractor) is distinct from the person's role. Workbase, ward, team and assignment may further qualify an action. A full utility-by-role permission matrix has not been approved.

The source inspection found task-specific checks for issuing, allocating, accepting and executing work. Those observations need reconciliation with the owner's intended model, not automatic adoption as policy. Record view/create/assign/accept/execute/review/export permissions separately for each task.
