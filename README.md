# iREPS Academy

This repository contains the iREPS Academy Body of Knowledge.

iREPS Academy is the source of truth for:

- iREPS User Manual
- in-app help popups
- training courses
- YouTube video scripts
- audio guides
- fieldwork guidance
- power systems learning material
- media and evidence training
- troubleshooting guides
- quick reference cards
- assessments and accreditation-ready course packs

The purpose of iREPS Academy is to help users understand both the iREPS App and the real-world fieldwork context behind iREPS.

The User Manual is only one part of the wider iREPS Academy ecosystem.
