# Screen-recording scripts

One script per form. Someone holds the phone, follows the script and records the screen. No editing suite, no studio: Android's own **Screen recorder** is enough.

These are for the release of **Sunday 27 September 2026** and match the Field Guide: https://claude.ai/artifact/PL4CibKktijutoGbysqVER

## Before you record

1. **Use DEV** (https://ireps2.web.app and the DEV app), never LIVE. Every script names the test meter it needs.
2. Sign in as a **field worker**, not a manager. A manager is told to issue the work and never gets the form, so the video would show the wrong thing.
3. Phone: put it on **Do not disturb**, turn the screen brightness up, and close other apps.
4. Android's **Screen recorder** is in the quick settings drawer. Turn **microphone on** if you are going to talk while you record; leave it off if the words will be added later.
5. Record **portrait**. That is how the workers hold the phone.
6. Take your time on the windows: stop on each one long enough to read it twice.

## How the scripts are written

- **SHOW** is what must be on the screen.
- **SAY** is the words. Say them in your own way; keep the app's words exactly as they are on the screen.
- **TAP** is what you press.
- Anything in quotation marks is on the screen exactly like that. Do not change it, even where it reads oddly, or the video and the app stop matching.

## When you have recorded

- Watch it once before you send it. If a window went by too fast, record that part again.
- No customer names, no ID numbers, no faces. A meter number on DEV is test data and is fine.
- Put the file in `07-media-and-evidence/` with the script's number in the name, for example `01-meter-inspection-2026-09-27.mp4`.
