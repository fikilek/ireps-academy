# Recovering Academy

The repository is https://github.com/fikilek/ireps-academy . With access to the owner's GitHub account, clone it on a replacement computer and check out main. Open README.md and the content/source registers first. Git history includes the pre-consolidation checkpoint of the existing dictionary, scripts and field-guide files.

Committed and pushed text, HTML, JavaScript, Python and other tracked training assets can be restored from GitHub. The source register stores provenance for imported documents; historical originals are either explicitly archived or recoverable from their source revision. Git hashes identify content history; SHA-256 fields identify the original source bytes at import.

External Claude artifacts, future YouTube uploads, credentials, live Firebase records, untracked files and unpushed changes are not backed up merely because a link or folder exists here. See EXTERNAL_DEPENDENCIES.md before claiming a complete media backup. No private keys or customer-data exports belong in this repository.

The field guide HTML can be read directly. Its generator is colocated and uses its own directory, rather than requiring C:/dev on the replacement computer. A normal browser needs network access for the external Google fonts; loss of font access does not remove the local text.

After every authorised backup, compare the local main commit with the remote main commit and check that all intended files are tracked. Retain the integration commit identifiers in the migration record or handover. A local commit alone does not protect against laptop loss.
