# Academy ownership and organisation

Status: owner-approved direction, established 23 September 2026.

Academy is the master of iREPS training documentation and terminology. This Codex Academy task coordinates content, reviews, structure and acceptance. Other agents may contribute under the contribution process; their implementation work does not automatically approve a lesson or change a product decision.

## Folder responsibilities

| Folder | Owns |
| --- | --- |
| 00-academy-governance | Decisions, contribution rules, source and content registers, historical assessments, recovery |
| 01-body-of-knowledge | Platform concepts and explanations reused by learning materials |
| 02-user-manual/shared | Cross-platform concepts and tasks with explicitly verified common behaviour |
| 02-user-manual/mobile | Mobile task instructions, prerequisites, outcomes and exceptions |
| 02-user-manual/web | Web task instructions, prerequisites, outcomes and exceptions |
| 03-in-app-help | Approved learner-facing help text and its source/release mapping |
| 04-courses | Learning objectives, sequences and references to lessons and assessments |
| 05-video-scripts | Demonstration scripts and recording/publication status |
| 06-audio-scripts | Audio adaptations and transcripts |
| 07-media-and-evidence | Training media and teaching about evidence quality; no bulk customer-data archive |
| 08-utility-systems | Electricity, water and sanitation subject knowledge |
| 09-fieldwork | Practical field guidance and release-specific training packs |
| 10-assessments | Questions, practical tasks, marking criteria and assessment status |
| 11-troubleshooting | Symptoms, explanations, user remedies and escalation routes |
| 12-quick-reference-cards | Short references derived from approved lessons |
| 13-utility-revenue-and-finance-controls | Revenue and financial-control subject knowledge |
| 14-faq | Reviewed recurring questions linked to authoritative answers |
| 15-dictionary | The one master terminology source and term reconciliation |

The existing 00–15 names are retained. Shared/mobile/web and source-assessments are the approved new subdivisions. Avoid copying a lesson into several folders: courses, media and help should identify the originating topic and release.

## Boundary with engineering

Business rules and schemas retain their technical authority in ireps-rules and ireps-schemas. Source code, technical design notes, tests and deployment evidence remain with the owning application. Mixed documents need explicit separation of learner guidance and engineering explanation. A copied historical source is not a competing active manual.

Runtime help components and calculations remain in application code. Academy owns wording and educational interpretation; integration into a runtime bundle is coordinated with the application developer and verified for that release.

Marketing owns campaign distribution and commercial Trials conversion. Academy owns product instruction and training for those journeys when they become defined.
