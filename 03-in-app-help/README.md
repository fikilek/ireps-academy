# In-app help

Editorial ownership is Academy; runtime components stay with application developers. The source register identifies Allocation Matrix help and mobile filter-help rendering. Inventory the actual help messages, link them to canonical topics, and record the Academy revision consumed by each application release. Dynamic calculations are engineering-owned and must not be moved out of executable code as part of this consolidation.
