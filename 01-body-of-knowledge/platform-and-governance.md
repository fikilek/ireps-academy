# iREPS platform and governance

Status: foundation draft, based on the owner's briefing and source inspection; detailed permissions remain open.

iREPS supports utilities, municipal entities and municipalities in managing assets, field work and revenue protection. Its mobile application captures work and evidence; its web application supports organisation, oversight and reporting. The Academy teaches both the tools and the utility/revenue context behind them.

## Keep three concepts separate

**Organisation:** utility/municipality, main contractor and subcontractor. Main-contractor and subcontractor relationships are not separate user-role codes.

**Person's role:** Super User (SPU), Administrator (ADM), Manager (MNG), Supervisor (SPV), Field Worker (FWR). Guest is excluded. Role alone is not a complete permission decision; organisation, workbase, team and assignment can matter. Inheritance still requires discussion.

**Where work belongs:** Country → Province → District Municipality → Local Municipality / Metro / workbase → Ward → ERF → Premise → Asset / Meter. A transaction (TRN) records work or an event; it is not an additional geography level.
