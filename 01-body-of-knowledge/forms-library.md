# iREPS forms — module library

Baseline: **25 September 2026**. Academy owns these training packages. The table contains **41 module families**: the existing Meter Discovery package and 40 new or expanded packages. A family can contain multiple explicitly named create/edit/action variants; it is not a count of unique screens. All five components exist for each family. Their depth and remaining evidence gaps are recorded honestly.

Start with the [meter lifecycle](meter-lifecycle-body-of-knowledge.md) and [iREPS Form Standards](ireps-form-standards.md). [Investigation method and limitations](../00-academy-governance/FORMS_INVESTIGATION_2026-09-25.md) explains the source coverage.
